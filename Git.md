# Git and GitHub SOPs

### Set Directory
``` bash
cd C:\\root-folder\\folder-name\\repo-folder
```

### Git Status
``` bash
git status
```

### Git Add
``` bash
# Stages single file or folder
git add <file>

# Stages all new, modified, and deleted files in the current directory
git add .
```

### Git Commit
``` bash
git commit -m "commit type: Add comment here"
```

``` bash
git branch -M main
```

``` bash
git remote add origin https://github.com/account-name/Repo-Name.git
```
### Git Pull
``` bash
git pull
```

### Git Push
``` bash
git push -u origin main
```

``` bash
git remote set-url origin https://[encryption]@github.com/account-name/Repo-Name.git
```

``` bash
git fetch origin
```
